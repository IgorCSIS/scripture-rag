# Contributing

1. Create a virtual environment with Python 3.11 and run `make install` (or `pip install -r requirements-dev.txt -e .`).
2. Read `DEVELOPMENT.md`.
3. Before a pull request: `make lint`, `make test`, and update docs (`docs/PRD.md` status, `docs/PROGRESS.md`).
4. New features get an FR id in `docs/PRD.md` with a testable acceptance criterion.
5. Commit messages: imperative mood, short subject, no tool attribution.
